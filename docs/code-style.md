# Руководство по стилю кода проекта «Магазин»

## Общие правила JavaScript

В проекте используется JavaScript стандарта ES2022 и среда выполнения Node.js 20.
Отступ - два пробела, строки ограничены 100 символами, в конце инструкций ставится точка с запятой.
Для объявления переменных используются const и let, ключевое слово var запрещено.
Строки записываются в одинарных кавычках, шаблонные строки - только при подстановке значений.

## Именование

Переменные и функции именуются в стиле camelCase, классы - в стиле PascalCase.
Константы уровня модуля записываются в стиле UPPER_SNAKE_CASE, например MAX_CART_ITEMS.
Имена CSS-классов задаются по методологии БЭМ: блок__элемент--модификатор,
например product-card__price--old.
Имена файлов компонентов - в стиле kebab-case: product-card.js, cart-summary.css.

## Асинхронный код

Для асинхронных операций используется async/await, цепочки then не применяются.
Каждый вызов fetch оборачивается в try/catch, ошибка записывается в журнал через модуль logger,
пользователю показывается понятное сообщение без технических подробностей.
Запросы к внешним сервисам выполняются с тайм-аутом 10 секунд через AbortController.

## Коммиты и ветки

Сообщения коммитов пишутся по соглашению Conventional Commits: feat, fix, docs, refactor, test.
Новая функциональность разрабатывается в ветке feature/<номер задачи>-<краткое-описание>.
Перед слиянием в ветку main обязательны прохождение тестов и ревью одного разработчика.
