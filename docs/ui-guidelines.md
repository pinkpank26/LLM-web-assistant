# Соглашения по вёрстке и интерфейсу

## Цвета и типографика

Цвета задаются только через CSS-переменные из файла variables.css:
--color-primary: #2563eb (основной синий), --color-danger: #dc2626 (ошибки),
--color-text: #1f2937, --color-bg: #f8fafc.
Основной шрифт интерфейса - Inter, запасной - system-ui. Базовый размер текста 16px,
межстрочный интервал 1.5. Размеры шрифтов указываются в rem.

## Адаптивность

Вёрстка выполняется по принципу mobile-first. Контрольные точки:
640px (планшет), 1024px (ноутбук), 1280px (широкий экран).
Сетка каталога товаров: 1 колонка на телефоне, 2 - на планшете, 4 - на ноутбуке и шире.

## Доступность

Все интерактивные элементы должны быть доступны с клавиатуры и иметь видимый фокус
(outline 2px solid var(--color-primary)). Изображения товаров обязательно имеют атрибут alt
с названием товара. Контраст текста - не ниже 4.5:1 по требованиям WCAG 2.1 уровня AA.
Иконки без подписи снабжаются атрибутом aria-label.

## Кнопки

Основная кнопка - класс button button--primary, вторичная - button button--secondary.
Высота кнопки 44px, скругление углов 8px. Во время отправки формы кнопка блокируется
атрибутом disabled и показывает индикатор загрузки.
