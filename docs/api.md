# REST API интернет-магазина

## Общие сведения

Базовый адрес API: /api/v1. Все ответы возвращаются в формате JSON в кодировке UTF-8.
Для защищённых маршрутов требуется заголовок Authorization: Bearer <токен>.
Токен доступа выдаётся маршрутом POST /api/v1/auth/login и действует 30 минут,
для обновления используется маршрут POST /api/v1/auth/refresh.

## Товары

GET /api/v1/products - список товаров. Параметры: page (номер страницы, по умолчанию 1),
limit (от 1 до 50, по умолчанию 20), category (идентификатор категории), sort (price, -price, name).
GET /api/v1/products/{id} - карточка товара: id, name, price, oldPrice, images, inStock.
Цены передаются в копейках целым числом, чтобы избежать ошибок округления.

## Корзина и заказы

POST /api/v1/cart/items - добавить товар в корзину, тело: { productId, quantity }.
В корзине может быть не более 30 позиций, количество одного товара - от 1 до 10.
POST /api/v1/orders - оформить заказ из текущей корзины. Возвращает номер заказа и статус created.
Возможные статусы заказа: created, paid, shipped, delivered, cancelled.

## Ошибки

Ошибки возвращаются с соответствующим HTTP-кодом и телом { error: { code, message } }.
400 - ошибка проверки данных, 401 - нет или истёк токен, 404 - ресурс не найден,
429 - превышен лимит запросов (100 запросов в минуту на пользователя), 500 - внутренняя ошибка.
